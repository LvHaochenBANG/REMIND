# CAMELS

`hydrology.npy` contains 12,699 time steps and 7 nodes. Source metadata
identifies the data as flow for CAMELS basin 13, with a daily sampling interval.
Calendar timestamps and physical node identifiers are not included.

`adj.npy` is a symmetric binary 7 × 7 matrix with self-loops. 
The retrieval similarity temperature used in the experiment is 0.7.

## Source and citation

This processed hydrological subset is derived from CAMELS. Please cite the original dataset publication:

Nans Addor, Andrew J. Newman, Naoki Mizukami, and Martyn P. Clark. “The CAMELS data set: catchment attributes and meteorology for large-sample studies.” Hydrology and Earth System Sciences, 21(10):5293–5313, 2017. [DOI](https://doi.org/10.5194/hess-21-5293-2017).
